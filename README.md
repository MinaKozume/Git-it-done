## 📌 Project Description
Our project is about **building an online coffee shop platform that allows customers to browse the menu,
place orders, and make payments seamlessly. The system also includes an admin panel for managing the
menu, tracking sales, and handling customer feedback. Visitors (non-logged-in users) can view the menu and
browse products but must create an account to place an order. The application is designed to enhance user
experience while streamlining daily operations for business owners.**.
